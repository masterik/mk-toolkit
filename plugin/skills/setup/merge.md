# Merging

Read by mkit's `finish` and `pr` skills; edit freely. Delete a section to go back to its default.

## Merge style

**Merge style: <merge | squash | rebase>.** `finish` integrates this repo's branches this way, on GitHub
(when the repository allows that method) and locally. Default: `merge` (a merge commit).

## Reviewers

Request review from: <`@handle`, `@org/team`>. `pr` uses this list instead of matching `CODEOWNERS`.
Default: the `CODEOWNERS` owners of the changed paths.
