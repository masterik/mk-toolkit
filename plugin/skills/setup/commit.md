# Commit conventions

How commits are worded in this repo. Read by mkit's `commit` skill; edit freely. Delete a section to go back
to its default (scopes discovered from history, subject ~72 characters).

## Scopes

Use one of these scopes. A change spanning several areas omits the scope.

- `<scope>`: <the area it covers>
- `<scope>`: <the area it covers>

## Subject length

Keep the subject line to **<n>** characters at most.
